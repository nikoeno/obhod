## Responsibility

The routing layer's config: TUN inbound, sniffing, DNS, outbounds per route, and rules per domain. Deterministic output.

## Public API

```go
package singbox

type Config struct {
    Binary          string          // path to sing-box
    TUN             TUNConfig       // interface name, address, stack (auto_route and strict_route are always on)
    DNS             DNSConfig       // direct DoH server, FakeIP range
    ClashAPI        string          // listen, default "127.0.0.1:9090"
    ClashSecret     string          // generated by the app at each start; never set by the user
    OwnProcesses    []string        // process names routed direct (our binaries + desync engine)
    BlockQUIC       bool            // default true (force TCP fallback)
    LogLevel        string
}

type TUNConfig struct {
    Name    string // default "splitter"
    Address string // CIDR; default 198.19.0.1/30
    Stack   string // system | gvisor | mixed; default mixed
}

type DNSConfig struct {
    DirectDoH   string // IP or https URL with an IP host (no bootstrap resolver); required
    FakeIPRange string // IPv4 prefix; default 198.18.0.0/16
}

// Tags of the generated outbounds; the last element of a Clash API chain is one of them.
const (TagDirect = "direct"; TagDesync = "desync"; TagTunnel = "tunnel"; TagProxy = "proxy")

type Outbounds struct {
    Tunnel json.RawMessage // VLESS+Reality outbound, from secrets
    Proxy  json.RawMessage // optional SOCKS/HTTP outbound
}

// Generate returns the full sing-box JSON config.
func Generate(cfg Config, ob Outbounds, t route.Table) ([]byte, error)

// Check runs "<binary> check -c <file>" and returns its output on failure.
func Check(ctx context.Context, binary, file string) error

// Command returns how to run sing-box with the given config file.
func Command(cfg Config, file string) (path string, args []string)
```

## Behavior / contract

Route mapping:

| Route | Outbound |
|---|---|
| direct | `direct` |
| desync | `desync`: a second direct outbound with its own tag, so connections show their route (traffic is mangled by the desync engine on the physical adapter) |
| tunnel | `tunnel` (VLESS+Reality) |
| proxy | `proxy` |
| block | reject |

- Rule order: own processes → direct; QUIC block; block; proxy; tunnel; desync; direct; final → the configured default (tunnel for unknown).
- Output is byte-identical for equal input (sorted keys and lists) → golden tests work.
- Field names and options must be verified against the **pinned sing-box version** docs, and every generated config must pass `sing-box check` in CI when the binary is available.

- Generated for sing-box 1.14.2 (verified with `sing-box check`): the legacy-free DNS format (`type: https` / `fakeip` servers), rule actions (`sniff`, `hijack-dns`, `route`, `reject`), `route.default_domain_resolver`, `process_name` for own processes (on Windows pass the base name with `.exe`).
- DNS: domains routed direct or desync resolve through `DirectDoH`; HTTPS/SVCB queries for everything else are rejected (they would leak the name); A/AAAA go to FakeIP, so tunnel/proxy domains resolve at the remote end. sing-box does not allow a fakeip default server, hence the rules by query type; the default server is `DirectDoH`.
- The TUN excludes private ranges (10/8, 169.254/16, 192.168/16, fc00::/7, fe80::/10) so the LAN stays on the physical network. The TUN address and the FakeIP range must not overlap (the defaults do not).
- `final` is always `tunnel` for now (G6 stays open: the final route has no config field).
- `ClashAPI` must be a loopback `host:port`; a non-loopback address is an error. `BlockQUIC` is a plain bool: the app config (M9) defaults it to true.
- `Check` returns the combined output of `sing-box check` wrapped in the error. `Command` is `run -c <file>`.
